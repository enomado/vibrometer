# Ссылки и литература

## Стандарты

- **ISO 21940-11** (бывш. ISO 1940-1) — допустимый остаточный дисбаланс.
  Классы качества G0.4 ... G630. Определяет допустимый `e*w` (мм/с).
  G6.3 — типично для электродвигателей, G2.5 — для турбин.

- **ISO 21940-14** — процедуры балансировки в собственных подшипниках (field balancing).

- **ISO 10816 / ISO 20816** — оценка вибрации машин. Границы "хорошо/допустимо/плохо".

## Книги

- **Левит М.Е., Рыженков В.М. "Балансировка деталей и узлов"** — 
  практическое руководство, формулы, примеры расчёта.

- **Тихонов А.Н. "Балансировка роторов"** — основы теории на русском.

- **Eisenmann & Eisenmann, "Machinery Malfunction Diagnosis and Correction"** — 
  библия вибродиагностики, подробно про балансировку (глава 11).

- **Kelm, R.D. "Rotor Balancing Tutorial"** (Vibration Institute) — 
  пошаговый гайд с формулами, отличное введение.

- **Wowk, V. "Machinery Vibration: Balancing"** — компактная книга, 
  сфокусирована именно на балансировке.

## Формулы (quick reference)

### Одноплоскостная балансировка (influence coefficient)
```
alpha = (V1 - V0) / T        -- коэффициент влияния
W = -V0 / alpha               -- корректирующий груз
```

### Двухплоскостная балансировка
```
det = a11*a22 - a12*a21

W1 = -(a22*V10 - a12*V20) / det
W2 = -(a11*V20 - a21*V10) / det
```

### Least squares (overdetermined, N датчиков > M плоскостей)
```
W = -(A^H * A)^(-1) * A^H * V0
```

### Допустимый остаточный дисбаланс (ISO 21940-11)
```
U_per = (G * M) / w          -- г*мм

G   — класс качества (мм/с), напр. 6.3
M   — масса ротора (кг)
w   — рабочая угловая скорость (рад/с)
```

### Амплитудно-фазовая характеристика (single-DOF)
```
A(r) = (m*e/M) * r^2 / sqrt((1-r^2)^2 + (2*zeta*r)^2)
phi(r) = atan2(2*zeta*r, 1 - r^2)

r = w/w_cr
zeta = damping ratio (типично 0.01-0.1 для роторов)
```
