# Обработка сигналов

## Задача

Из сырого сигнала виброметра (тысячи точек за оборот, шум, гармоники)
нужно выделить **1x компоненту** — вибрацию на частоте вращения.

## Уровни качества сигнала

### Уровень 1: Максимальная амплитуда за ран (peak-hold)
- Одно число с прогона
- Достаточно для метода трёх пусков (только амплитуды)
- Минимум по hardware: не нужен быстрый ADC, можно аналоговый пиковый детектор
- **Минус**: нет информации о частоте — ловим максимум от чего угодно
  (резонанс крепежа, внешние вибрации). Нужна аналоговая фильтрация вокруг 1x.

### Уровень 2: Амплитуда по оборотам (огибающая)
- Одно значение амплитуды (peak-to-peak или RMS) на каждый оборот
- Видим стабильность, можем усреднять, видим разгон/выбег
- Нужен ADC быстрее частоты вращения (10-20 сэмплов/оборот) + keyphasor для нарезки
- Достаточно для influence coefficient без фазы

### Уровень 3: Полный сигнал (waveform) — РЕКОМЕНДУЕМЫЙ
- Полный waveform с ADC, сотни-тысячи точек за оборот
- Нужен для: FFT, выделения 1x/2x/3x, определения фазы, диагностики
- Hardware: ADC 10-50 кГц, буфер, DMA
- Из полного сигнала можно получить уровень 1 и 2 программно
- FFT позволяет отфильтровать 1x от шума без аналогового фильтра
- Можно диагностировать проблемы (2x = несоосность, дробные = люфт)

**Решение проекта**: уровень 3 (полный сигнал) как основной,
с программной деградацией до 1-2 при необходимости.

## Режим измерения: фиксированные обороты vs прогон

### Фиксированные обороты — основной режим
- Вышел на рабочие обороты → стабилизация (5-10 сек) → измерение
- Именно так работают промышленные балансировочные станки
- Достаточно для серийной балансировки однотипных роторов

### Прогон (coast-up / coast-down) — опциональный режим
- От нуля до макс оборотов и обратно
- Результат: Bode plot (амплитуда + фаза vs RPM)
- Нужен один раз при настройке под новый тип ротора
- Определяет: критические скорости, демпфирование, режим работы

Когда нужен прогон:
- Первичная настройка станка
- Подозрение на работу вблизи резонанса
- Гибкие роторы (несколько критических скоростей)

## Источники данных

### Виброметр (ADC)
- Частота дискретизации: типично 10-50 кГц
- Сигнал: сумма гармоник (1x, 2x, 3x...) + шум
- Единицы: мВ → через чувствительность датчика → мм/с или мкм

### Keyphasor (опционален)
- Один импульс за оборот (цифровой вход или таймер capture)
- Из периода: `RPM = 60 / T_period`
- Фронт импульса = опорная точка (0° вала)

### Определение RPM без keyphasor
Из спектра вибрации:
```
1. FFT от сигнала виброметра
2. Поиск доминирующего пика в ожидаемом диапазоне оборотов
3. f_rot = частота пика
4. RPM = f_rot * 60
```
Точность зависит от длины FFT-блока (разрешение = f_sample / N).

## Методы выделения 1x

### 1. FFT (Fast Fourier Transform)

Преобразование блока данных в частотную область.

```
1. Набрать блок N точек (N = степень двойки, типично 1024-4096)
2. Применить оконную функцию (Hanning)
3. FFT → спектр
4. Найти бин, ближайший к частоте вращения: bin = round(f_rot * N / f_sample)
5. Амплитуда = |X[bin]| * 2/N
6. Фаза = arg(X[bin]) — но относительно начала блока, не keyphasor!
```

**Привязка фазы к keyphasor**: нужно знать, где в блоке данных был импульс keyphasor.
Сдвиг фазы: `phi_corrected = phi_fft - 2*pi*f_rot*t_keyphasor`

Плюсы: видно весь спектр, можно анализировать 2x, 3x и т.д.
Минусы: дискретизация по частоте (spectral leakage), нужна привязка фазы.

### 2. Синхронное усреднение (Time Synchronous Averaging, TSA)

Усреднение сигнала синхронно с оборотами (по keyphasor).

```
1. По импульсам keyphasor нарезать сигнал на отрезки = 1 оборот
2. Ресэмплировать каждый отрезок до одинаковой длины (N точек на оборот)
3. Усреднить K отрезков поточечно
4. Результат: периодический сигнал, очищенный от асинхронного шума
5. FFT от усреднённого → 1x компонента
```

Плюсы: отличное шумоподавление (SNR растёт как sqrt(K)), автоматическая привязка к keyphasor.
Минусы: нужно много оборотов, нужен keyphasor.

### 3. Tracking filter (полосовой фильтр, следящий за RPM)

Узкополосный фильтр с центральной частотой = текущий RPM.

```
1. Из keyphasor определять текущий RPM в реальном времени
2. Перестраивать полосовой фильтр на f = RPM/60
3. Выход фильтра = 1x компонента
4. Амплитуда = огибающая выхода
5. Фаза = из сравнения с keyphasor
```

Плюсы: работает в реальном времени, следит за изменением скорости.
Минусы: переходные процессы при изменении RPM.

## Практические аспекты

### Сколько оборотов усреднять?
- Минимум 8-16 для стабильного результата
- 32-64 для точной балансировки
- Больше — лучше шумоподавление, но дольше ждать

### Оконные функции для FFT
- **Hanning** — стандартный выбор, хороший компромисс
- **Flat-top** — точнее амплитуда, хуже частотное разрешение
- Для синхронно нарезанных данных (точно целое число периодов) — окно не нужно

### Единицы измерения
- Перемещение (мкм) — для низких частот, подшипники скольжения
- Скорость (мм/с) — стандарт ISO, широкий диапазон
- Ускорение (м/с²) — для высоких частот

Преобразование (для гармонического сигнала на частоте w):
```
displacement = velocity / w = acceleration / w^2
velocity = displacement * w = acceleration / w  
acceleration = displacement * w^2 = velocity * w
```
