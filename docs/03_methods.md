# Методы балансировки

## 1. Метод коэффициентов влияния (Influence Coefficient Method)

Самый универсальный метод. Работает в любом режиме (до/резонанс/зарезонансный),
не требует знания модели ротора — чисто экспериментальный.

### Одноплоскостная балансировка

**Шаг 1**: Измерить начальную вибрацию `V0` (амплитуда + фаза)

**Шаг 2**: Поставить пробный груз `T` (масса `m_t` на угле `theta_t`)
- Груз должен быть достаточным для заметного изменения вибрации (>30% от V0)
- Но не слишком большим (не больше 2-3x начальной вибрации)

**Шаг 3**: Измерить вибрацию с пробным грузом `V1`

**Шаг 4**: Вычислить коэффициент влияния:
```
alpha = (V1 - V0) / T
```
где все величины — комплексные (вибровекторы).

`alpha` показывает: "сколько вибрации создаёт единичный груз в этом месте"

**Шаг 5**: Вычислить корректирующий груз:
```
W = -V0 / alpha
```

Результат — комплексное число: `|W|` = масса, `arg(W)` = угол установки.

**Шаг 6**: Снять пробный груз, поставить корректирующий `W`. Проверить.

### Двухплоскостная балансировка

Для двух плоскостей коррекции и двух датчиков.

**Измерения** (4 пуска):
1. Начальный: `V10`, `V20` (вибрация на датчиках 1 и 2)
2. Пробный груз в плоскости 1: `V11`, `V21`
3. Убрать груз 1, пробный груз в плоскости 2: `V12`, `V22`

**Коэффициенты влияния** (матрица 2x2):
```
a11 = (V11 - V10) / T1
a12 = (V12 - V10) / T2
a21 = (V21 - V20) / T1
a22 = (V22 - V20) / T2
```

**Корректирующие грузы** (решение системы):
```
| a11  a12 |   | W1 |     | V10 |
|          | * |    | = -  |     |
| a21  a22 |   | W2 |     | V20 |
```

Решение через обратную матрицу 2x2:
```
det = a11*a22 - a12*a21

W1 = -(a22*V10 - a12*V20) / det
W2 = -(a11*V20 - a21*V10) / det
```

### Least Squares (overdetermined)

Если датчиков больше чем плоскостей (N > M), система переопределена.
Решение методом наименьших квадратов:

```
W = -(A^H * A)^(-1) * A^H * V0
```

где `A^H` — эрмитово-сопряжённая матрица (транспонирование + комплексное сопряжение).

## 2. Метод трёх пусков (без keyphasor)

Когда нет датчика фазы — доступна только амплитуда (не вектор).

**Шаг 1**: Измерить начальную амплитуду `A0`

**Шаг 2**: Поставить пробный груз `T` на 0°, измерить `A1`

**Шаг 3**: Переставить груз на 120°, измерить `A2`

**Шаг 4**: Переставить груз на 240°, измерить `A3`

Три амплитуды + три известных положения позволяют восстановить вектор.
Геометрически — пересечение трёх окружностей.

Аналитически:
```
O = A0^2  (начальная вибрация в квадрате)
R1 = A1^2
R2 = A2^2  
R3 = A3^2

// Пробный вектор T в трёх положениях:
T1 = T * e^(j*0)      = T
T2 = T * e^(j*2pi/3)  = T * (-0.5 + j*0.866)
T3 = T * e^(j*4pi/3)  = T * (-0.5 - j*0.866)

// Из |V0 + alpha*Tk|^2 = Rk получаем систему для Re(V0/alpha) и Im(V0/alpha)
```

Метод менее точен (нет фазовой информации, ошибки накапливаются),
но не требует keyphasor — дешевле в оборудовании.

## 3. Метод четырёх пусков (Four-Run)

Вариация трёх пусков: 0°, 90°, 180°, 270°. Четвёртый пуск — контрольный,
повышает точность. Вычисления проще (ортогональные позиции).

```
X = (A1^2 - A3^2) / (4 * T)   // реальная компонента
Y = (A2^2 - A4^2) / (4 * T)   // мнимая компонента

W_correction = -(X + j*Y)
```

## 4. Метод X/Y пары (Influence Coefficient без keyphasor)

Замена keyphasor на пару ортогональных виброметров (X + Y) на каждой опоре.

**Идея**: два датчика под 90° дают обе компоненты вибровектора напрямую:
```
V = V_x + j*V_y
```

Это полноценный комплексный вибровектор — можно применять стандартный
influence coefficient method без модификаций.

**Для двух плоскостей**:
- 4 датчика (2 пары X/Y, по паре на опору)
- 2 плоскости коррекции
- 3 пуска (как с keyphasor): начальный + пробный в плоскости 1 + пробный в плоскости 2

**Особенности**:
- Фаза не привязана к абсолютному положению вала — "плавающий ноль"
- Для корректной работы ротор не должен переустанавливаться между пусками
  (или нужна визуальная метка для ручной привязки)
- RPM определяется из спектра вибрации (пик на 1x) вместо keyphasor

**Определение RPM без keyphasor**:
```
1. FFT от сигнала любого виброметра
2. Найти доминирующий пик в ожидаемом диапазоне оборотов
3. f_rot = частота пика
4. RPM = f_rot * 60
```

Это основной рекомендуемый метод для данного проекта.

## 5. Метод трёх пусков для двух плоскостей (без keyphasor, без X/Y пары)

Когда доступны только одиночные виброметры (1 на опору) и нет keyphasor.

Нужно 7 пусков:
1. Начальный: амплитуды A10, A20 на обоих датчиках
2. Пробный груз в плоскости 1 на 0°:   A11, A21
3. Пробный груз в плоскости 1 на 120°:  A12, A22
4. Пробный груз в плоскости 1 на 240°:  A13, A23
5. Пробный груз в плоскости 2 на 0°:   A14, A24
6. Пробный груз в плоскости 2 на 120°:  A15, A25
7. Пробный груз в плоскости 2 на 240°:  A16, A26

Каждая тройка пусков (2-4 и 5-7) восстанавливает один столбец матрицы 
коэффициентов влияния через пересечение окружностей.

**Минусы**: много пусков, нелинейная математика, ниже точность.
Использовать как fallback когда нет возможности поставить X/Y пару.

## Выбор метода

| Критерий | Influence + keyphasor | Influence + X/Y пара | Три пуска (амплитуды) | Четыре пуска |
|---|---|---|---|---|
| Датчик фазы | Keyphasor | 2 вибро × 90° | Не нужен | Не нужен |
| Кол-во датчиков (2 плоскости) | 2 вибро + 1 keyphasor | 4 вибро | 2 вибро | 2 вибро |
| Кол-во пусков (1 плоскость) | 2 | 2 | 4 | 5 |
| Кол-во пусков (2 плоскости) | 3 | 3 | 7 | 10 |
| Точность | Высокая | Высокая | Средняя | Выше средней |
| Сложность математики | Линейная | Линейная | Нелинейная | Линейная |
| **Рекомендация** | Если есть keyphasor | **Основной метод** | Fallback | Fallback |
