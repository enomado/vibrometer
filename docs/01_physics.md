# Физика дисбаланса ротора

## Центробежная сила дисбаланса

Вал с дисбалансом создаёт центробежную силу:

```
F = m * e * w^2
```

- `m` — масса дисбаланса (кг)
- `e` — эксцентриситет (расстояние центра масс от оси вращения, м)
- `w` — угловая скорость (рад/с)

Произведение `m * e` называется **статический дисбаланс** (г·мм или кг·м).

## Вибровектор

Вибрация от дисбаланса — гармонический сигнал на частоте вращения (1x).
Описывается **вибровектором** — комплексным числом:

```
V = A * e^(j*phi)
```

- `A` — амплитуда вибрации (мкм перемещения, мм/с скорости, или м/с² ускорения)
- `phi` — фаза относительно опорной метки (keyphasor), радианы

В декартовой форме: `V = A*cos(phi) + j*A*sin(phi)`

Вибровектор — центральный объект всей системы. Все операции балансировки — 
это арифметика над вибровекторами (комплексными числами).

## Датчики

### Виброметр (акселерометр)
Измеряет вибрацию в одной проекции. Для полной картины нужно минимум 
2 датчика (две проекции — обычно горизонталь и вертикаль, или два подшипника).

Выход: аналоговый сигнал (напряжение пропорционально ускорению/скорости/перемещению).

### Keyphasor (датчик фазы / тахометр)
Один импульс за оборот вала. Даёт:
- **RPM** — из периода между импульсами
- **Опорную фазу** — момент прохождения метки = 0° вала

Keyphasor **опционален**. Без него фаза восстанавливается альтернативными методами (см. ниже).

Варианты keyphasor (если используется):
- **Оптический** — отражающая метка + фотодатчик
- **Индуктивный** — паз/шпонка на валу (работает через масло и грязь)
- **Hall-датчик** — магнит на валу
- **Encoder** — на торце вала

### Пара ортогональных виброметров (X/Y) — замена keyphasor

Два виброметра на одной опоре, установленные под 90° друг к другу:

```
V_x = A*cos(w*t + phi)
V_y = A*sin(w*t + phi)

// Фаза восстанавливается без keyphasor:
phi = atan2(peak_Y, peak_X)
```

Даёт полный комплексный вибровектор (амплитуда + фаза) за один пуск.
Фаза "плавает" (нет привязки к абсолютному положению вала), но для
балансировки это допустимо — важна разность фаз между пусками, а не абсолют.

**Ограничение**: нужна визуальная метка на роторе или фиксированная установка
между измерениями, чтобы пробный груз ставился в известную позицию.

## Проекции (плоскости коррекции)

Для **статической** балансировки достаточно одной плоскости коррекции.
Для **динамической** (моментной) — нужны минимум две плоскости.

### Конфигурация A: с keyphasor (классическая)
- 2 виброметра (по одному на каждой опоре)
- 2 плоскости коррекции
- 1 keyphasor
- **3 пуска** для двухплоскостной балансировки

### Конфигурация B: без keyphasor, пара X/Y
- 2 пары виброметров (X+Y на каждой опоре, итого 4 датчика)
- 2 плоскости коррекции
- Без keyphasor
- **3 пуска** для двухплоскостной балансировки (как с keyphasor!)

### Конфигурация C: без keyphasor, только амплитуды
- 2 виброметра (по одному на каждой опоре)
- 2 плоскости коррекции
- Без keyphasor
- **7 пусков** для двухплоскостной (метод трёх пусков × 2 плоскости + начальный)

## Связь вибрации и дисбаланса

Вибрация на подшипнике — линейная комбинация дисбалансов во всех плоскостях:

```
V_i = sum_j( alpha_ij * U_j )
```

- `V_i` — вибровектор на i-м датчике
- `U_j` — дисбаланс в j-й плоскости
- `alpha_ij` — коэффициент влияния (transfer function)

Для двух плоскостей и двух датчиков:

```
| V1 |   | a11  a12 |   | U1 |
|    | = |          | * |    |
| V2 |   | a21  a22 |   | U2 |
```

Задача балансировки — найти `alpha_ij` (через пробные пуски) и решить обратную задачу.
