# Hardware: датчики, ADC, передача данных

## Датчики вибрации: самодельный velocity transducer

Катушка + постоянный магнит + пружинный подвес. Пассивный датчик,
генерирует ЭДС пропорционально скорости вибрации (мм/с).

Выход: аналоговый (мВ), прямо на ADS1256. Не требует питания.

Чувствительность промышленных: ~20-30 мВ/(мм/с).
Рабочая полоса: ~10-1000 Гц (определяется резонансом подвеса).

Преимущества:
- Выход в скорости — стандарт ISO, не нужно интегрировать/дифференцировать
- Пассивный — нет питания, нет шума от электроники датчика
- Аналоговый — идеальная пара с ADS1256
- Простая конструкция для самостоятельного изготовления

Конструктив: магнит закреплён на корпусе (опоре), катушка на пружинном
подвесе (инерционная масса). При вибрации корпус движется, катушка отстаёт
за счёт инерции → относительное перемещение → ЭДС.

## Конфигурация датчиков (минимальная)

- 2 velocity transducer (самодельные, по одному на каждой опоре)
- 1 keyphasor (обязателен для итеративной балансировки)

## Частота дискретизации

Расчёт для мотора 2000 RPM (33.3 Гц — частота вращения):

| Цель | Нужная полоса | Найквист | С запасом |
|---|---|---|---|
| Только 1x (балансировка) | 33 Гц | 67 Гц | 500 Гц |
| До 10x гармоник (диагностика) | 333 Гц | 667 Гц | 2 кГц |

**Решение**: 2 кГц — достаточно для балансировки и базовой диагностики.
~60 сэмплов на оборот при 2000 RPM.

## Формат фрейма

Keyphasor передаётся как бит-флаг в каждом сэмпле (один поток, без синхронизации):

```
struct Sample {
    vibro1: i16,    // 2 байта (или i24 = 3 байта при 24-бит ADC)
    vibro2: i16,    // 2 байта
    flags: u8,      // 1 байт, bit 0 = keyphasor фронт в этом сэмпле
}
// = 5 байт/сэмпл (i16) или 7 байт/сэмпл (i24)
```

## Битрейт

| Разрядность | Байт/сэмпл | @ 2 кГц | @ 20 кГц |
|---|---|---|---|
| 16-бит | 5 | 80 кбит/с | 800 кбит/с |
| 24-бит | 7 | 112 кбит/с | 1.1 Мбит/с |

## WiFi ESP32

ESP32 WiFi реальная пропускная способность: 1-5 Мбит/с (TCP).
Наш поток 80-112 кбит/с — **1-2% от ёмкости канала**. Запас огромный.

Даже при 20 кГц / 24-бит (1.1 Мбит/с) — влезает.

## Буфер

При 2 кГц, 5 байт/сэмпл = 10 КБ/с.

Для балансировки нужно ~32 оборота усреднения.
При 2000 RPM это ~1 секунда = 10 КБ буфер.

ESP32 RAM ~520 КБ — запас 50x.

## ESP32 ADC — не подходит

ESP32 встроенный ADC: 12-бит SAR, но:
- **ENOB ~9-10 бит** (шум). Динамический диапазон ~60 дБ.
- **ADC2 не работает с WiFi** (общие ресурсы radio). Остаётся только ADC1.
- **Плохая линейность** на краях диапазона (0-100 мВ и >3.1 В).
- Для грубой балансировки (40 дБ, отношение 100:1) — впритык.
- Для точной (класс G2.5) — не хватит.

ESP32-S3: чуть лучше, но всё равно 12-бит с шумом. Не решает проблему.

## Рекомендуемая схема: ESP32 + внешний ADC

ESP32 — WiFi мост и управление. ADC — внешний, по SPI.

### Варианты внешних ADC

| Чип | Разрядность | Каналы | Скорость | Интерфейс | Примечание |
|---|---|---|---|---|---|
| **ADS131M02** | 24 бит | 2 simultaneous | 32 кСэмпл/с | SPI | Simultaneous sampling, нет задержки между каналами. Оптимальный. |
| **ADS1256** | 24 бит | 8 (мультиплексор) | 30 кСэмпл/с | SPI | **Есть в наличии.** Мультиплексорный — задержка между каналами ~33 мкс, нужна программная компенсация фазы. |
| ADS1115 | 16 бит | 4 (мультиплексор) | 860 Сэмпл/с | I2C | Медленный. Только для ≤500 Гц. |

**В наличии: ADS1256** — начинаем с него. Мультиплексорный, задержка между каналами
компенсируется программно (при 2000 RPM сдвиг ~0.4° — мало, но учитываем).

**Апгрейд на будущее: ADS131M02** — simultaneous sampling, компенсация не нужна.

### Keyphasor

GPIO interrupt на ESP32. При 2000 RPM = 33 фронта/с.
Jitter прерывания ESP32 ~несколько мкс — при периоде оборота 30 мс
это ошибка фазы ~0.06°. Несущественно.

### Подключение датчиков к ADS1256

ADS1256 в дифференциальном режиме: CMRR ~100-110 дБ,
подавляет синфазные наводки (50 Гц, наводки мотора).

```
Velocity transducer 1:
  провод A ──> AIN0 (P)    ── дифф. канал 0
  провод B ──> AIN1 (N)
  
Velocity transducer 2:
  провод A ──> AIN2 (P)    ── дифф. канал 1
  провод B ──> AIN3 (N)

AIN4-AIN7 — свободны (запас)
```

### Итоговая схема

```
VT1 (AIN0/AIN1) ──┐
                    ├── ADS1256 ── SPI ──> ESP32 ──> WiFi/TCP ──> PC
VT2 (AIN2/AIN3) ──┘                         │
                                              │
Keyphasor ──────────────── GPIO IRQ ─────────┘
```

3 канала ввода: 2 дифф. ADC + 1 GPIO. WiFi ~80 кбит/с @ 2 кГц.
