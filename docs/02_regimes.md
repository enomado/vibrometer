# Режимы работы: до/резонанс/зарезонансный

## Критическая скорость

Каждый ротор на опорах — колебательная система с собственной частотой w_cr (критическая скорость).
Поведение вибрации принципиально зависит от соотношения w/w_cr.

## Дорезонансный режим (w << w_cr)

- Вектор вибрации **совпадает по направлению** с вектором дисбаланса
- Фазовый сдвиг ≈ 0°
- Амплитуда растёт пропорционально w^2
- **Простейший случай**: куда показывает фаза — там тяжёлое место

Применение: тихоходные роторы, вентиляторы, барабаны.

## Резонансный режим (w ≈ w_cr)

- Амплитуда вибрации **максимальна** (ограничена только демпфированием)
- Фазовый сдвиг ≈ 90° (отстаёт от дисбаланса)
- Малые изменения скорости — большие изменения амплитуды и фазы
- **Опасная зона**: нужна коррекция фазы на ~90°

Применение: проход через критическую при разгоне/торможении. 
Балансировка в этом режиме возможна, но требует аккуратности.

## Зарезонансный режим (w >> w_cr)

- Фазовый сдвиг ≈ 180° (вибрация противоположна дисбалансу)
- Амплитуда стабилизируется (не зависит от скорости)
- **Инверсия**: тяжёлое место — **напротив** того, куда показывает фаза

Применение: турбины, шпиндели, высокооборотные роторы.

## Переходная зона

На практике переход плавный. Фаза меняется от 0° до 180° через ~90° на резонансе.
Точная зависимость определяется коэффициентом демпфирования (damping ratio zeta):

```
phi(r) = atan2(2*zeta*r, 1 - r^2)

где r = w/w_cr — отношение частот
```

Амплитуда:

```
A(r) = (m*e/M) * r^2 / sqrt((1-r^2)^2 + (2*zeta*r)^2)

где M — масса ротора
```

## Определение режима

Для определения в каком режиме работаем:
1. Снять данные на нескольких оборотах (Bode plot — амплитуда и фаза vs RPM)
2. Найти пик амплитуды — это w_cr
3. Рабочая скорость ниже/выше/около пика → режим

Или: поставить пробный груз в известное место. Если фаза вибрации:
- совпадает с положением груза → дорезонансный
- 90° отставание → резонанс  
- 180° → зарезонансный
